# 🩺 Diabetes Prediction using Machine Learning

## 📌 Overview

This project uses Machine Learning to predict whether a patient is diabetic based on medical attributes such as glucose level, BMI, insulin, blood pressure, and age. The model was built using the **K-Nearest Neighbors (KNN)** algorithm and achieved an accuracy of **76.56%**.
